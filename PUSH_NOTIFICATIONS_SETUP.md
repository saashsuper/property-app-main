# Web Push Notifications Setup for Work Order Assignment

Contractor Admin users receive web push notifications when a work order is assigned to their contractor company. Uses Laravel Web Push (no Firebase required).

## When Notifications Are Sent

1. **Create** – Work order created and assigned to a contract company (outsource)
2. **Update** – Work order contractor assignment changed to a contract company
3. **Reassign** – Work order reassigned to a Contractor Admin

## Setup Requirements

### 1. Laravel Backend (already configured)

VAPID keys were generated by `php artisan webpush:vapid` and added to `.env`:
- `VAPID_PUBLIC_KEY`
- `VAPID_PRIVATE_KEY`

**Do not change these keys** – existing push subscriptions will break.

### 2. PWA – Enable Push Notifications

1. **Service Worker**: The PWA must have a service worker registered (Vite PWA or similar).
2. **Request permission**: Call `registerPushSubscription()` from `utils/pushNotifications.ts` after login.
3. **Example** – add to Dashboard or after login:
   ```typescript
   import { registerPushSubscription } from '../utils/pushNotifications';

   // After user logs in and lands on dashboard
   useEffect(() => {
     if (user && user.user_type?.name === 'Contractor Admin') {
       registerPushSubscription();
     }
   }, [user]);
   ```

### 3. API Endpoints

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/mobile-api/auth/vapid-public-key` | Public – returns VAPID public key for PWA subscription |
| POST | `/mobile-api/auth/update-push-subscription` | Auth required – save push subscription |

**Push subscription payload** (from `PushSubscription.toJSON()`):
```json
{
  "endpoint": "https://...",
  "keys": {
    "p256dh": "base64url...",
    "auth": "base64url..."
  },
  "contentEncoding": "aesgcm"
}
```

## Files

| File | Purpose |
|------|---------|
| `app/Notifications/WorkOrderAssignedNotification.php` | Web push notification content |

## PWA Service Worker

The PWA must handle push events in the service worker:

```javascript
// In service worker (e.g. sw.js or vite-plugin-pwa)
self.addEventListener('push', (event) => {
  const data = event.data?.json() || {};
  const options = {
    body: data.body || 'New notification',
    icon: '/favicon.ico',
    data: { url: data.url }
  };
  event.waitUntil(
    self.registration.showNotification(data.title || 'Notification', options)
  );
});

self.addEventListener('notificationclick', (event) => {
  event.notification.close();
  if (event.notification.data?.url) {
    event.waitUntil(clients.openWindow(event.notification.data.url));
  }
});
```
